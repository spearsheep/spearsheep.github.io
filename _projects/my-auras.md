## From a profile to a page

My Auras combines an AI-assisted builder with a visual editor. A creator can start from a prompt or résumé, choose a template, then arrange images, video, links, and other content into a page that reflects their work.

## Built to keep evolving

The product includes reusable and remixable community templates, media uploads, responsive layouts, and analytics. React and TypeScript power the frontend, while Convex handles the shared application data and backend workflows.
